# الحَكَم الذكي | Football Laws RAG

مساعد عربي تجريبي لشرح قوانين كرة القدم بالاستناد إلى وثائق رسمية وإظهار الأدلة والمراجع.

## حالة المشروع

تم تنزيل وفحص المصدر الأساسي: قوانين اللعبة 2026/27 بالعربية (236 صفحة، والنص قابل للاستخراج). يحتوي سجل المصادر على 33 مصدرًا رسميًا: 32 حالة تنزيل واستخراج، ومصدر PDF أساسي موجود محليًا وقابل لاستخراج النص، دون حالات فشل بحسب `source_collection_report.json`. تشمل الملفات النصوص المستخرجة للمصادر المكملة، وملف القوانين العربي صفحةً صفحة. يلزم تدقيق جودة النص العربي وربط كل مصدر ومقتطف بمراجعة موثقة قبل بناء الفهرس. لم تُقَس Recall@5 أو RAGAS بعد، ولم تُجرَ اختبارات المستخدمين.

راجع [`PROJECT_CHECKLIST.md`](PROJECT_CHECKLIST.md) لمتابعة كل متطلبات المساق وعناصر التسليم الخمسة. لا تُعدّ أي نتيجة أو متطلب منجزًا قبل التحقق الفعلي منه.

## الملفات

- `domain.md`: تعريف المجال والنطاق والقيود.
- `data/sources_manifest.csv`: سجل المصادر وحالة التحقق والتنزيل.
- `data/raw/ifab_laws_2026_27_ar.pdf`: المصدر الرسمي المرفق.
- `data/extracted/laws_pages.jsonl`: استخراج أولي صفحة بصفحة مع رقم الصفحة.
- `data/eval/extraction_qa.json`: ملاحظات فحص جودة الاستخراج.
- `data/eval/golden_questions_draft.json`: 20 مسودة سؤال مرتبطة بمواد وصفحات؛ ليست بعد مجموعة التقييم الذهبية النهائية.
- `data/eval/source_candidates.md`: مصادر IFAB الرسمية المرشحة وتحققها الحالي.
- `scripts/collect_sources.py`: أداة جمع الوثائق الرسمية من الروابط الموثقة، مع سجل نجاح/فشل وبصمات SHA-256.
- `data/eval/source_collection_report.json`: سيُنشأ عند تشغيل أداة الجمع في بيئة تسمح بالاتصال الخارجي.
- `architecture.md`: تصميم مبدئي وقرارات تقنية لم تُحسم بعد.
- `API_KEY_GUIDE.md`: شرح المفتاح السري، حفظه بأمان، وخطة الاستخدام ضمن الرصيد.
- `.gitignore`: يمنع رفع المفاتيح والبيئة الافتراضية وفهارس المتجهات؛ ملفات corpus النصية وسجل المصادر تبقى ضمن المشروع لمراجعتها وإعادة بناء الفهرس.
- `scripts/extract_pdf.py`: أداة إعادة الاستخراج وإنتاج تقرير الصفحات التي تحتاج مراجعة.
- `data/raw/`: نسخ المصدر الخام محلية، مستثناة من Git لتقليل حجم المستودع؛ يمكن إعادة جمعها بالأداة عند الحاجة.
- `data/eval/`: مكان ملفات أسئلة التقييم والتقارير لاحقًا.

## الخطوة التالية

الخطوة التالية تدقيق corpus المستخرج والتحقق من عدم تكرار المحتوى، ثم مراجعة الصفحات العربية التي يتطلب استخراجها تحققًا بصريًا. بعد ذلك نكمل تعريف مجموعة 30 سؤالًا ذهبية ثم بناء واختبار خط الاسترجاع. لا تُحسب هذه المصادر تلقائيًا كـ33 وثيقة مستقلة قبل إزالة التكرار والتحقق من استقلال المنشورات. ولتفاصيل مفتاح API راجع `API_KEY_GUIDE.md`.
